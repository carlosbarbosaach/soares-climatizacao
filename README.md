# Soares Climatização — proposta Base48 Digital

Projeto demonstrativo em Next.js + TypeScript + Tailwind CSS.

## Dados aplicados
- WhatsApp: (47) 9 9719-6961
- Região: Bombinhas e região
- Instagram: @soares.climatizacao
- Serviços comunicados: instalação, infraestrutura, manutenção e higienização
- Identidade visual baseada no material enviado: azul profundo + laranja + branco

## Conversão
A conversão principal é WhatsApp. O formulário não salva dados: apenas monta a mensagem e abre a conversa.

## Antes de publicar
1. Confirmar domínio final e atualizar `metadataBase`, `sitemap.ts` e `robots.ts`.
2. Substituir ilustrações por fotos reais do cliente quando disponíveis.
3. Confirmar exatamente a área atendida e os serviços antes de manter o texto definitivo.
4. Adicionar GA4/GTM e Meta Pixel, caso o cliente faça campanhas.
5. Inserir avaliações reais apenas se fornecidas pelo cliente.

## Rodar localmente
```bash
npm install
npm run dev
```
